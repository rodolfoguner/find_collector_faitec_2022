# Historical archive

`project-2022/` contains the original planning, requirements, modeling, and
academic delivery documents for Find Collectors.

These files are preserved as a record of the initial vision. They are not the
source of truth for the current API behavior and may describe technology, data
models, or features that have changed during modernization.

For current information, start with the [documentation index](../README.md) and
the [roadmap](../roadmap.md).
